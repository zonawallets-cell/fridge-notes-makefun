A one-line note from a passive-aggressive fridge, written for the
[make.fun](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7)
bounty "Notes From a Passive-Aggressive Fridge".

`main.py` (pure Python stdlib, no dependencies) prints the line and writes it
to `/output/entry.txt`:

> My door alarm has gone off 12 times today. I am not broken. You are just indecisive and hungry.
